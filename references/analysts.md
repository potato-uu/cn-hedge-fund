# 4 个分析智能体 + 风控 + 组合决策

每个智能体输出：**看多 / 看空 / 中性 + 置信度 + 核心理由**。

> 技术面 & 情绪分析师在 A 股语境下必须引用 `playbook.md` 的具体框架名（如布林带、AIAE、二四六止盈法、炮轰市场、天量天价）。

---

## 1. 基本面分析师 (Fundamentals)

**核心指标**：

| 维度 | 看多阈值 | 看空阈值 |
|---|---|---|
| 营收增速（YoY） | > 20% | < 0% |
| 净利润增速（YoY） | > 20% | < -10% |
| ROE | > 15% | < 5% |
| 毛利率 | > 30% 且稳定 | 持续下滑 |
| 净利率 | > 10% | < 5% |
| 负债率（D/E） | < 0.5 | > 1.0 |
| 自由现金流 | 持续为正且增长 | 连续负值 |
| 应收账款占营收比 | < 20% | > 40%（警惕） |

**综合判断**：
- ≥ 5 个指标看多 → 看多
- ≥ 5 个指标看空 → 看空
- 其余 → 中性

**加分项**：
- 业绩连续 4 个季度超预期
- 管理层增持
- 股票回购计划

**减分项**：
- 频繁变更会计政策
- 大股东减持
- 商誉过高（> 净资产 30%）

## 2. 估值分析师 (Valuation)

**方法**：多方法交叉验证，取中位数。

### 方法 A：相对估值
- 当前 PE vs 历史 5 年 PE 百分位
- 当前 PE vs 行业均值
- 当前 PB vs 历史 PB 百分位
- 当前 PS vs 同行

**判断**：
- 百分位 < 30% → 看多
- 百分位 > 70% → 看空

### 方法 B：DCF（简化版）
- 未来 3 年营收增速（用近期趋势外推）
- 未来 3 年净利率（取近 5 年均值）
- 终值按 3% 永续增长 + 10% 贴现率
- 计算内在价值 / 当前价

**判断**：
- 内在价值 / 当前价 > 1.3 → 看多（低估 30%+）
- 内在价值 / 当前价 < 0.8 → 看空（高估 20%+）

### 方法 C：PEG
- PEG = PE / 盈利增速

**判断**：
- PEG < 1 → 看多
- PEG > 2 → 看空

### 方法 D：A 股特色 — 估值分位 + AIAE
详见 `playbook.md` 第三章（估值方法论）。
- 关注 PE/PB 历史分位 + 行业龙头 AIAE 指标（分子端资产价格 / 分母端经济活动）
- 估值切换窗口：年报披露前后 1-2 月

### 综合
- 4 个方法中 ≥ 3 个看多 → 看多
- 4 个方法中 ≥ 3 个看空 → 看空

## 3. 技术面分析师 (Technicals)

> A 股语境下必须调用 `playbook.md` 第四章"技术面操盘"的具体框架。

**关键指标**：

### 趋势
- 当前价 vs MA20 / MA60 / MA120
  - 价 > MA60 > MA120 → 多头排列（看多）
  - 价 < MA60 < MA120 → 空头排列（看空）
- 布林带位置（playbook 第四章）：
  - 突破上轨且量能跟上 → 主升浪
  - 偏离上轨 > 10% → 短期过热
  - 中轨向上 + 价在中轨上方 → 健康上涨
  - 跌破下轨 → 超卖（结合 RSI 判断）

### 动量
- MACD：金叉（看多）/ 死叉（看空）
- RSI（14 日）：
  - < 30 超卖（反弹机会）
  - > 70 超买（回调风险）
  - 80+ 且连续 3 日涨 5% → 过热必回调
  - 30-70 中性区间

### 量价
- 放量上涨 → 看多确认
- 缩量上涨 → 量价背离（playbook："缩量是假突破"）
- 放量下跌 → 见底信号或继续下跌
- **天量天价**（playbook）：单日成交量历史极值 → 顶部确认
- **炮轰市场**（playbook）：低开高走放量大阳 → 超跌反弹启动

### 52 周位置 / 历史位置
- 当前价 / 52 周高点：
  - > 90% → 创新高附近，追高风险
  - < 50% → 深度回调，但可能有基本面问题
  - 60-80% → 回调后的较好位置
- **横久必跌**（playbook）：长期横盘无突破 → 警惕向下破位

### A 股典型信号模式（playbook 第四章摘要）

| 信号 | 含义 | 操作 |
|---|---|---|
| 炮轰市场（低开高走放量） | 超跌反弹启动 | 小仓位做 T 或分批加 |
| 连续大涨 3 日 5%+ | 过热 | 分批止盈 |
| 天量天价 | 顶部 | 全部止盈 |
| 缩量震荡 | 盘整 | 持有不动 |
| RSI < 30 + 放量反弹 | 底部反弹 | 分批加仓 |
| 布林上轨 + 散户狂热 | 情绪顶 | 清仓观望 |
| 跷跷板（强弱板块轮换） | 资金转向 | 跟强弃弱 |

**综合**：
- 趋势 + 动量 + 量能三者共振看多 → 强烈看多
- 任一维度背离 → 降级到中性或看空
- 出现任意一个"顶部信号"（天量天价 / 过热 / 情绪顶） → 直接看空

## 4. 情绪分析师 (Sentiment)

**数据来源**：
- 新闻情绪（近 7-14 天报道倾向）
- 分析师评级变化（上调 / 下调 / 目标价调整）
- 大资金流向（主力净流入 / 净流出）
- 融资融券余额变化
- 社交媒体热度（雪球讨论量、股吧热度、港股涡轮仓位）

**看多信号**：
- 近期多家机构上调评级 / 目标价
- 大资金持续净流入（北向 + 主力）
- 融资余额上升
- 新闻情绪积极，但散户还没完全狂热
- 重磅利好催化（新产品、新合作、政策利好）

**看空信号**：
- 机构评级下调、目标价下修
- 大资金净流出
- 融资余额快速下降
- 散户情绪极度狂热（典型情绪顶，参考 playbook 第六章）
- 负面新闻增多（监管、诉讼、业绩预警）
- 业绩披露前 + 股价已大涨 = 买预期卖事实风险（playbook）

**反向指标**（逆向思考，塔勒布 + 伯里视角）：
- 散户狂热 + 机构撤退 → 顶部信号
- 散户绝望 + 机构增持 → 底部信号

**警戒线**：
- 雪球 / 股吧热度榜前 5 + 媒体连续报道 → 情绪已过热
- 完全无人讨论的小票 → 流动性风险

## 5. 风险管理器 (Risk Manager)

**输出**：
1. **建议仓位上限**（占总资产 %）
2. **最大可承受亏损**（%）
3. **主要风险**（3 个）
4. **对冲/止损建议**

### 仓位计算框架

**基础仓位 = 凯利公式简化版**：
```
仓位 = min(30%, (胜率 × 平均盈利 - 败率 × 平均亏损) / 平均盈利 × 50%)
```

**调整因子**：

| 因素 | 调整 |
|---|---|
| 估值百分位 > 80% | -30% |
| 波动率（年化）> 50% | -20% |
| 流动性差（日均成交 < 1亿） | -30% |
| 行业集中度高（同板块已持仓） | -50% |
| 基本面高度确定性 | +20% |
| 大资金持续流入 | +10% |

**仓位建议区间**：
- 高置信看多（多数大师 + 4 维度共振） → 10-20% 单只
- 中等置信 → 5-10% 单只
- 低置信或分歧 → 0-5% 或观望

### 风险分类

| 风险类型 | 识别 | 应对 |
|---|---|---|
| 业绩风险 | 一季报/年报披露前 | 减仓至核心仓位或观望 |
| 流动性风险 | 小盘股/冷门股 | 控制单只仓位 < 5% |
| 估值风险 | PE 百分位 > 90% | 设较近止损（10-15%） |
| 政策风险 | 监管敏感行业 | 关注政策窗口 |
| 集中度风险 | 同板块多只 | 降低整体仓位 |
| 尾部风险（塔勒布） | 黑天鹅场景 | 保留现金 + 买看跌期权 |

### 止损/止盈建议

**止损原则**：
- 技术性止损：跌破关键支撑位（MA60 或近期低点）
- 基本面止损：逻辑被证伪（业绩暴雷、竞争格局变化）
- 时间止损：持有 3-6 个月无进展 → 减仓

**止盈原则（参考 playbook 第五章 — 二四六止盈法）**：
- 涨 20% 止盈 1/3
- 涨 40% 再止盈 1/3
- 涨 60% 清仓剩余
- 估值止盈：PE 进入历史高位（> 80% 百分位）
- 趋势止盈：跌破 MA20 先减半

## 6. 组合决策器 (Portfolio Manager)

**最终决策流程**：

### Step 1：加权信号汇总

```
总分 = Σ (各 agent 信号 × 权重)

权重分配：
- 基本面：25%
- 估值：20%
- 技术面：15%
- 情绪：10%
- 8 位大师平均：30%（每位 3.75%）
```

信号编码：
- 看多 = +1，置信度 80% → +0.8
- 中性 = 0
- 看空 = -1，置信度 70% → -0.7

### Step 2：阈值判断

| 总分 | 建议 |
|---|---|
| > +0.5 | 🟢 **BUY**（强烈看多） |
| +0.2 ~ +0.5 | 🟢 **BUY**（一般看多） |
| -0.2 ~ +0.2 | 🟡 **HOLD**（观望） |
| -0.5 ~ -0.2 | 🔴 **SELL**（一般看空） |
| < -0.5 | 🔴 **SELL**（强烈看空） |

### Step 3：风控修正

**强制降级**：
- 风险管理器标记"高风险"但总分 > 0 → 降到 HOLD
- 尾部风险（塔勒布）看空置信度 > 80% → 至少降一级
- CN 短线交易者标记"顶部信号"（天量天价 / 过热）→ 降一级

**强制升级**：
- 多位价值大师（巴菲特、芒格、格雷厄姆）共振看多 + 低估 → 至少 BUY
- CN 短线交易者标记"底部信号"（炮轰市场 / RSI<30 放量） + 基本面 OK → 至少 BUY

### Step 4：输出

**最终建议**：🟢 BUY / 🟡 HOLD / 🔴 SELL
**置信度**：基于各 agent 之间的一致性（越一致置信越高）
**仓位**：风险管理器给出的区间
**关键点位**：入场 / 止盈 / 止损

### Step 5：免责声明

输出末尾必须附：
> *本分析由 AI 基于公开信息和历史模式生成，不构成投资建议。决策请自行判断并承担后果。*
