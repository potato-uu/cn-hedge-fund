# Factor Layer — 详细计算规则（v2）

> **v2 变化**：原 "4 分析师（基本面/估值/技术/情绪）" 合并进 Factor Layer 的 7 因子。
> Factor Layer 是 Decision 的**唯一**依据，人格不再投票。
> 本文件定义每个因子的打分阈值、跨市场差异、边界案例处理。

每个因子输出：**+2 强多 / +1 多 / 0 中 / -1 空 / -2 强空** + 关键数据（1-2 条）。

跳过的因子必须在报告中显式列出（原因：Step 0 Instrument Router 判定不适用）。

---

## 1. Quality（质量）

**核心指标**：ROE / ROIC、利润率稳定性、FCF 匹配度、负债结构

### 打分

| 条件 | 分数 |
|---|---|
| ROE >20% 且 5 年标准差 <3pp，D/E <0.3，FCF/净利润 >0.8 | +2 |
| ROE 15-20% 或以上但波动较大，D/E 0.3-0.6 | +1 |
| ROE 10-15%，D/E 0.6-1.0 | 0 |
| ROE 5-10%，D/E 1.0-1.5 | -1 |
| ROE <5% 或负值，或 D/E >1.5，或 FCF 连续负 | -2 |

### 跨市场差异

| 类型 | 调整 |
|---|---|
| 银行 / 保险 | 换 ROA（+2 阈值 >1.5%）+ 资本充足率（核心一级 >10%）+ 不良率（<1.5%）+ NIM 趋势 |
| 周期股 | 看**全周期 ROE**（取近 7-10 年中位数，而非当前值）+ 产能利用率 |
| 未盈利生科 | 跳过 ROE。换 Cash runway（>24m +1 / 12-24m 0 / <12m -2）+ Pipeline 质量 |
| ETF | 跳过 Quality 整项（转移到 ETF 专属因子）|

### 加分项

- 业绩连续 4 季度超预期：+0.5
- 管理层增持 / 股票回购计划：+0.5

### 减分项

- 频繁变更会计政策：-1
- 大股东减持（>1% 股本 近 3 月）：-0.5
- 商誉 >净资产 30%：-0.5

## 2. Growth（增长）

**核心指标**：营收 YoY、净利 YoY、持续性

### 打分

| 条件 | 分数 |
|---|---|
| 营收+净利 YoY >30%，近 4 季度可持续，毛利率不降 | +2 |
| YoY 20-30%，可持续 | +1 |
| YoY 10-20% | 0 |
| YoY 0-10% 或放缓 | -1 |
| YoY <0% 或业绩暴雷 | -2 |

### 跨市场差异

- **周期股**：看行业产品价格位置 + 产能利用率，不只看利润增速
- **银行**：看信贷增速 + 净息差走势
- **ETF**：跳过（转到"成分盈利增速"辅助因子）
- **未盈利生科**：跳过。换核心管线推进速度（临床推进阶段 / readout 进度）

## 3. Valuation（估值）

**方法**：多方法交叉，至少 3 种同向才打 ±2。

### 方法矩阵（按 Step 0 开关）

| 方法 | 科技/成长 | 银行/保险 | 周期 | 生科 | ETF |
|---|---|---|---|---|---|
| PE 历史分位 | ✅ 主 | ⚠️ 弱化 | ❌ PE 失真 | ❌ 无盈利 | ❌ |
| PB 历史分位 | ⚠️ | ✅ 主 | ✅ 主 | ⚠️ | ❌ |
| PEG | ✅ | ❌ | ❌ | ❌ | ❌ |
| DCF | ✅ | ❌ 换 DDM | ⚠️ 周期调整 | ❌ | ❌ |
| 股息率 | ⚠️ | ✅ 主 | ⚠️ | ❌ | ✅ 跟踪分红 |
| 指数估值分位 | — | — | — | — | ✅ 主 |

### 打分

| 条件 | 分数 |
|---|---|
| 历史分位 <20% 且 ≥3 种方法同向低估 | +2 |
| 历史分位 20-40% | +1 |
| 历史分位 40-60% | 0 |
| 历史分位 60-80% | -1 |
| 历史分位 >80% 或 DCF 高估 >30% | -2 |

### A 股特殊：AIAE 与估值切换

- AIAE 指标（资产价格 / 经济活动）见 playbook.md 第三章
- 估值切换窗口：年报披露前后 1-2 月，可能触发 Valuation 分数跳跃

### PEG 细则（仅科技/成长）

- PEG <0.5 → +2
- PEG 0.5-1.0 → +1
- PEG 1.0-1.5 → 0
- PEG 1.5-2.0 → -1
- PEG >2.0 → -2

## 4. Trend（趋势）

**核心指标**：MA 排列、布林轨位置、52 周位置

### 打分

| 条件 | 分数 |
|---|---|
| 价 > MA20 > MA60 > MA120（多头排列）+ 布林中轨向上 + 52 周 50-80% | +2 |
| 多头排列 + 52 周 40-60% | +1 |
| 价在 MA60 附近震荡，无明确方向 | 0 |
| 破 MA60 或空头排列初现 | -1 |
| 空头排列 或 52 周 >95%（追高）或 天量天价顶部 | -2 |

### A 股 playbook 信号映射（仅 A 股 / 港股部分启用）

| playbook 形态 | Trend 分数 |
|---|---|
| 炮轰市场（低开高走放量大阳） | +2 |
| 缩量上涨 | 0（量价背离，降级） |
| 放量上涨 + MA 多头 | +2 |
| 天量天价 | -2 |
| 连续 3 日涨 5%+ RSI>80 | -1（过热）|
| 布林上轨 + 散户狂热 | -2 |
| 跌破下轨 + 放量反弹 + RSI<30 | +1 |
| 横久必跌（长期横盘无突破）| -1 |
| 跷跷板（板块轮换被弃）| -1 |

### 美股调整

关闭 A 股 playbook 框架名。改用：
- 多头/空头排列
- 52 周位置
- 布林轨相对位置
- 成交量相对 20 日均量

## 5. Liquidity（流动性 / 资金面）

**核心指标**：日均成交、主力资金流向、北向/融资融券（仅 A 股）

### 打分

| 条件 | 分数 |
|---|---|
| 日均成交充足 + 主力 5 日净流入 + 北向持续加仓（A 股） | +2 |
| 成交正常 + 资金微幅流入 | +1 |
| 成交萎缩但无明显流出 | 0 |
| 主力持续净流出 | -1 |
| 大资金撤退 + 融资快速下降（A 股） + 天量流出 | -2 |

### 开关矩阵（由 Step 0 控制）

| 字段 | A 股 | 港股 | 美股 | ETF |
|---|---|---|---|---|
| 日均成交 | ✅ | ✅ | ✅ | ✅ |
| 主力净流入（东财）| ✅ | ⚠️ | ❌ | ⚠️ |
| 北向资金 | ✅ | ❌ | ❌ | ⚠️ 宽基 |
| 融资融券 | ✅ | ❌ | ❌ | ❌ |
| 期权隐含波动 | ❌ | ⚠️ | ✅ | ✅ |
| ETF 资金流（申赎） | — | — | — | ✅ 主 |

## 6. Regime（宏观 + 行业周期）

**核心指标**：行业生命周期、宏观环境、政策

### 打分

| 条件 | 分数 |
|---|---|
| 行业景气上行 + 流动性宽松 + 政策支持 + 机构资金流入 | +2 |
| 景气平稳 + 宏观中性 | +1 or 0 |
| 景气下行初期，但无系统性风险 | -1 |
| 加息周期 + 政策打压 + 行业出清 | -2 |

### 常见 Regime 场景（2026 上下文，动态更新）

- **AI 算力**：景气上行中期 + 政策支持 + capex 加速 → +1~+2
- **新能源**：供需出清末段 + 储能订单改善 → 0~+1
- **创新药**：BD 出海放量 + 港股 18A 解冻 → +1~+2
- **银行**：NIM 触底 + 利率维稳 → 0
- **房地产**：长期出清 + 政策托底但需求弱 → -1
- **黄金**：地缘 + 降息预期 → +1~+2

### Regime 强制降级

- Regime = -2 → Factor 总分即使为正，也强制降级到 HOLD

## 7. Tail Risk（尾部风险 / 塔勒布）

**核心指标**：杠杆、集中度、黑天鹅敞口、商誉

### 打分

| 条件 | 分数 |
|---|---|
| 资产负债表稳健 + 业务多元 + 反脆弱特性（动荡受益） | +2 |
| 一般稳健 | +1 or 0 |
| 有单一依赖（客户 / 地区 / 产品）但可识别 | -1 |
| 高杠杆（D/E >2）或 单一客户 >50% 或 商誉 >净资产 50% 或 高估值+高预期（一次失望就崩） | -2 |

### 特殊敞口检查

- **海外业务 >30%**：标注地缘风险
- **关税敏感**（出口 / 进口 >20% 营收）：标注贸易政策风险
- **未盈利 + runway <12m**：Tail Risk 直接 -2
- **重大诉讼 / 监管调查未决**：Tail Risk 至少 -1

### 塔勒布特色提醒

即便 Factor 总分为 Strong BUY，Tail Risk = -2 的标的：
- 仓位上限砍半
- 建议杠铃策略：主体仓位用更保守标的替代，本标的放入高赔率敞口（<5%）

## Decision Layer：加权与强制规则

### 加权公式

```
总分 = Σ(因子 × 权重) / Σ(权重)

默认权重：
  Quality      2.0
  Growth       2.0
  Valuation    2.0
  Trend        1.5
  Liquidity    1.0
  Regime       1.5
  Tail Risk    2.0
```

**总权重 12**。总分理论范围 [-2, +2]。

### 资产类型权重调整

| 类型 | 调整 |
|---|---|
| ETF | Quality/Growth 权重置 0，改为指数估值分位权重 3，跟踪误差/集中度权重 1 |
| 银行 | Trend/Liquidity 权重降 0.5，Tail Risk 权重升 0.5 |
| 周期股 | Valuation 权重升 0.5（因基本面周期性失真），Regime 权重升 0.5 |
| 未盈利生科 | Quality/Growth/Valuation 权重降，Tail Risk 升到 3.0，Regime 权重升 |

### 强制规则（必须在报告中显式检查）

1. **Tail Risk = -2 + 总分 >0** → 降一级 + 仓位砍半
2. **Regime = -2** → 至少降一级
3. **数据完整度 <0.5** → 强制 HOLD，标注"信号不充分"
4. **周末 / 非交易时段，无实时数据** → HOLD 观望
5. **≥ 3 个因子被 Step 0 跳过** → 置信度 ≤ 0.6，建议仅作观察用
6. **因子标准差 >1.0（高度分歧）** → 置信度下调 0.2

## Risk Manager：Risk Budget 仓位（非凯利）

> **硬规则**：无 N≥50 同类交易样本库时，禁用凯利公式。改用固定 risk budget。

### 仓位上限表（见 SKILL.md）

详见 `SKILL.md` Decision Layer · 仓位 · Risk Budget 段。

### 信号 × 上限矩阵

| 信号 | 建议使用上限比例 |
|---|---|
| 🟢🟢 Strong BUY | 80-100% |
| 🟢 BUY | 50-80% |
| 🟡 HOLD | 不加仓（新仓不开） |
| 🔴 SELL | 减至上限的 20-50% |
| 🔴🔴 Strong SELL | 清仓 |

### 止盈止损

**止损**：
- 技术性：跌破 MA60 或近期低点
- 基本面：Factor 任一项从 +1 跌到 -1，且无改善迹象
- 时间：持有 6 个月无进展

**止盈（参考 A 股 playbook "二四六止盈法"，仅 A 股适用）**：
- 涨 20% 止盈 1/3
- 涨 40% 再止盈 1/3
- 涨 60% 清仓剩余

美股 / 港股：按估值分位 >80% 或 Trend 从 +2 降到 0 触发分批止盈。

## 置信度（四子项分解）

```
confidence = min(data_completeness, source_quality, factor_consistency, market_fit)
```

| 子项 | 满分 | 打分依据 |
|---|---|---|
| data_completeness | 1.0 | 所需字段全部拿到 + 新鲜度 <30d |
| source_quality | 1.0 | 基本面来自公告/交易所，技术面来自主流行情 |
| factor_consistency | 1.0 | 标准差 <0.5 |
| market_fit | 1.0 | Step 0 分类准确 + 开关矩阵完全适用 |

**输出格式**：
```
置信度：数据 0.9 / 源 0.8 / 一致性 0.6 / 适配 1.0 → 综合 0.6
```

不要只给综合百分比，必须展示 4 个子项。
