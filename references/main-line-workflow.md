# 主线推演子工作流 (Main Line Deduction)

## 何时触发

用户问："主线是什么 / 当前主线 / 赛道推演 / 半年主线判断 / 组合整体复盘 / 行业主线"。

## 核心原则

继承 `SKILL.md` 的 8 框架 + "可见推演步骤"元原则。每一步必须显示数据源、引用日期、推理链。

## 严格约束

1. **时间窗口明确**：所有 WebSearch 必须带当前年份 + "latest / 2026 / 最近" 等关键词；默认半年窗口
2. **板块必须落到 ETF 代码**：结论不能停在"看好新能源"，必须给出 `159750 / 515790 / 159995` 等具体 ETF
3. **6 大赛道标准分类**：AI 算力 / 新能源 / 创新药 / 军工 / 黄金宏观 / 地缘
4. **等级化标注**：🟢🟢 强主线 / 🟢 主线 / 🟡 次主线 / 🔴 非主线 / ⛔ 陷阱

## 工作流（按顺序）

### Step 0：确定时间窗口

当前日期 = YYYY-MM-DD，半年前日期 = SINCE（用于过滤"半年内"）。

### Step A：5 路 WebSearch 并行

| 赛道 | 关键词（必带当前年份） |
|---|---|
| Fed / 宏观 | `"Federal Reserve rate path inflation YYYY outlook"` |
| AI 算力 | `"Nvidia TSMC AI chip YYYY capex demand semiconductor"` |
| 中国经济 | `"China stimulus PBOC YYYY property consumer outlook"` |
| 黄金 / 地缘 | `"gold price YYYY outlook central bank geopolitical"` |
| 创新药 | `"China biotech licensing YYYY ADC oncology Hong Kong"` |

根据当前热点可替换 1-2 个（如战争升级 → 换成 `"oil price YYYY Iran Hormuz strait"`）。

### Step B：分类与事实提取

对每条 WebSearch 结果提取：
- **核心事实**（数字 + 时间）
- **含义**（对股价 / 板块的影响方向）
- **来源链接**（markdown 可点）

### Step C：主线交叉验证表

| 赛道 | 宏观催化 | 产业数据 | 市场反应 | 一致性 | 等级 |
|---|---|---|---|---|---|

一致性档位：
- ✅ **强共振**（宏观 + 产业 + 市场都同向）→ 🟢🟢 强主线候选
- ⚠️ **方向同节奏分歧**（宏观看多但产业数据滞后）→ 🟡 次主线
- ❌ **内外冲突**（宏观利好但市场不买账）→ 🔴 非主线 / ⛔ 陷阱

### Step D：8 框架过滤

每条候选主线都过一遍：

| 框架 | 检查问题 |
|---|---|
| ① 林奇"卖赢家" | 用户操作是否落入"卖盈利留亏损"误区？ |
| ② 芒格 inversion | 做完这个动作钱去哪儿？下一步是什么？ |
| ③ 德鲁肯米勒集中度 | 这条主线在当前组合里有几只 ETF？是否重复？ |
| ④ 第一性原理 | 拆"口号"（如"AI 长牛"）到本质逻辑 |
| ⑤ Risk Budget | 无 N≥50 样本库禁用凯利；单只上限见 `SKILL.md` Decision Layer |
| ⑥ 三层过滤 | 基本面 ✓ / 估值 ✓ / 技术面 ✓ 全过才算强主线 |
| ⑦ 具体化 | 操作必须给：ETF 代码 + 金额 + 触发条件 |
| ⑧ 行为金融 | 警惕"想翻身 / 想赌一把"、警惕锚定成本价 |

### Step E：落到 ETF 与操作

每条强主线必须对应：
1. **ETF 代码 + 简称**（如 `159995 半导体 ETF`）
2. **当前价 / 历史分位**
3. **技术位**（布林轨、MA60、RSI 见 `playbook.md`）
4. **操作建议**：加仓 / 持有 / 减仓 / 清仓
5. **触发条件**：具体涨跌幅 + 量能 + 价位

**示例**（仅演示格式）：
```
🟢🟢 AI 算力 — 强主线
  ETF：159995 半导体 ETF（当前价 ¥X.XX，PE 分位 45%）
  技术面：布林中轨向上 + RSI 55（健康上涨）
  操作：持有，跌破 MA60 减半，涨至历史分位 80% 分批止盈
  触发：¥X.XX 止损 / ¥X.XX 止盈第一档
```

## 常见错误（之前犯过的）

1. ❌ WebSearch 不带年份 → 拉到老新闻混淆判断
2. ❌ 结论不对应 ETF 代码 → 用户无法执行
3. ❌ 只看一个维度（宏观 OR 产业 OR 市场）就下结论 → 必须三者交叉验证
4. ❌ 不标等级 → 用户分不清"强主线"和"次主线"该怎么操作
5. ❌ 只给方向不给触发条件 → 违反具体化原则
