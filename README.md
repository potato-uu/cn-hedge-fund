# cn-hedge-fund

> 中国 A 股 / 港股 / 美股多智能体投资分析 — 8 位投资大师人格 + 4 个分析师 + 风控 + A 股实战手册。
> 纯 prompt 驱动，无外部代码依赖，可用于任何支持 skill / prompt 加载的 AI 助手。

## 特点

- **13 个独立视角**：巴菲特、芒格、格雷厄姆、林奇、德鲁肯米勒、伯里、塔勒布、A 股短线交易者，再加基本面 / 估值 / 技术面 / 情绪四个分析师
- **A 股语境增强**：包含一份蒸馏自 A 股实盘的 2500+ 行 `playbook.md`（布林带、量价、AIAE、二四六止盈、炮轰市场、跷跷板等框架）
- **双工作流**：单标的深度分析（7 步）+ 主线推演子流程（赛道级）
- **决策思维框架**：8 个元原则（林奇卖赢家综合征、芒格反向、德鲁肯米勒集中度、第一性原理、凯利公式、三层过滤、具体化、行为金融）
- **零配置**：所有数据通过 WebSearch 获取，无需 API key
- **可扩展**：留有本地 override 点，用户可建立私有 skill 注入个人持仓、RAG 知识库、定制人格

## 使用方式

### 通用 AI 助手（ChatGPT / Claude.ai / Gemini / 其他）

把 `SKILL.md` + `references/*.md` 的内容贴入你的 AI 对话作为系统 / 上下文提示，然后问：
- `分析一下 300750`
- `用这套框架分析 NVDA 和 9988.HK`
- `当前 A 股主线是什么`

### Claude Code / 支持 skill 机制的助手

```bash
git clone https://github.com/<your-user>/cn-hedge-fund.git ~/.claude/skills/cn-hedge-fund
```

然后触发词会自动激活 skill，跑完 8 大师 + 4 分析师 + 风控，输出完整报告。

### 其他 AI 编程工具（Cursor / Cline / OpenClaw）

把 `SKILL.md` 的内容作为系统提示或 rule 文件引入，`references/` 作为附加知识库。

## 决策思维框架（8 元原则）

1. **林奇"卖赢家综合征"检测**：散户卖盈利留亏损是反逻辑的
2. **芒格 Inversion**：不问"该不该买"，问"做完这步钱去哪儿"
3. **德鲁肯米勒集中度**：持仓 > 15 只 = 低费率指数
4. **第一性原理**：拆"长期持有"、"定投微笑"等口号到本质
5. **凯利公式**：仓位 ∝ 胜率 × 盈亏比
6. **三层过滤**：基本面 / 估值 / 技术面独立判断
7. **具体化**：不说"建议减仓"，说"卖 X 份 / ¥X,XXX"
8. **行为金融校准**：警惕亏损厌恶的反向补偿

## A 股实战手册（playbook.md）涵盖

- 第一章 **宏观与事件驱动**：Fed 降息周期、央行逆回购、通胀/滞胀、战争模板、关税、五年规划、非农/CPI/GDP/PMI
- 第二章 **行业周期与主线识别**：生命周期 + 8 行业剧本（新能源 / AI / 创新药 / 军工 / 白酒 / 金融 / 房地产 / 周期）+ 财报季
- 第三章 **估值方法论**：历史分位 / PEG / PB / 估值切换 / AIAE / 巴菲特指标 / ERP / 估值陷阱 / 泡沫识别
- 第四章 **技术面操盘**：布林带、量价、炮轰市场、RSI、AIAE、跳空、日内 T、天量天价、过热、阳包阴、跷跷板、BOLL 定投、二四六止盈、VIX、整数关口、横久必跌
- 第五章 **仓位管理与进出场**：二四六止盈法（涨 20% 卖 1/3 → 40% 卖 1/3 → 60% 清剩余）/ 定投启停 / 分批原则 / 金字塔建仓
- 第六章 **投资心理学**：10 个心理陷阱 + 6 阶段情绪周期 + 纪律清单

## 本地 Override（私人化扩展）

本 skill 是通用框架。若要注入个人持仓、私有 RAG、定制人格，可在本地建立 override skill（不入本仓库），例如：

```
~/.claude/skills/cn-hedge-fund-<yourname>/
├── SKILL.md                          # 触发词与本 skill 协同
└── references/
    └── holdings.md                   # 个人持仓与成本基础
```

override skill 不需要重复本 skill 的所有内容，只需在 trigger 中追加个人 context（如"优先引用持仓对应的 ETF"、"附加个人 RAG 知识库查询"）。
